# Fate/Grand Index

A Fate/Grand Order index of every NA servant and Craft Essence (Past Chaldea), plus your own Spirit Origin List: roster, Guests, parties, rankings, versus and a summoning simulator. It ships as one self-contained HTML file that saves everything in your own browser.

Status: **alpha** (`0.x`). Version 1.0.0 will be the full website and app.

## Layout

| Path | What it is |
|---|---|
| `dist/Fate_Grand_Index.html` | The built page, the file you open in a browser. Built from `src/`, never edited by hand. |
| `src/page.html` | The page itself; `@@styles@@` and `@@app@@` mark where the style sheets and the script go. |
| `src/styles/*.css` | The style sheets, joined in name order. |
| `src/app/*.js` | The script, joined in name order into one script (the files share one scope; they are parts, not separate modules). |
| `src/assets/` | Pictures that are built into the page (logo, class icons, card art, the skill icon sheet). |
| `src/data/atlas_data.js` | NA servant and Craft Essence data, generated by `tools/gen_atlas.py`. Don't edit it by hand. |
| `data/atlas/` | The Atlas Academy NA exports that `atlas_data.js` is made from (gzipped). |
| `tools/build.py` | Puts `src/` together into `dist/Fate_Grand_Index.html`. |
| `tests/` | Browser tests (Playwright) and `tests/run.py` to run them. |
| `legacy/` | The old build (a 0.7.1 page plus patch scripts `patch_v8.py` … `patch_v21.py`), kept read-only for reference. `src/` was cut from its 0.19.0 output and rebuilds it byte for byte. |

## Building

Needs Python 3 (standard library only). Node is used for a syntax check when it is installed.

```sh
python3 tools/build.py           # writes dist/Fate_Grand_Index.html and build/seeded.html (sample roster, for tests)
python3 tools/build.py --check   # fails if dist/ is not what src/ builds
```

Commit `dist/Fate_Grand_Index.html` together with the `src/` change that produced it.

When the Atlas Academy data changes, replace the exports in `data/atlas/` and run:

```sh
python3 tools/gen_atlas.py       # rebuilds src/data/atlas_data.js
python3 tools/build.py
```

## Tests

```sh
pip install -r tests/requirements.txt && python3 -m playwright install chromium
python3 tests/run.py             # builds, then runs every suite (-j 2 runs two at a time)
python3 tests/run.py craft       # only suites whose name contains "craft"
```

The tests don't need the internet: most suites swap the pictures that would come from Atlas Academy for placeholders, and the sample roster in `tests/fixtures/sample-roster.json` is built into `build/seeded.html`. Screenshots go to `build/test-work/`.

GitHub Actions runs the build check and every suite on each push to `main` and on every pull request (`.github/workflows/test.yml`).

## Live NA updates (0.21.0)

Home's "On NA now" block reads Atlas Academy's NA export files (`info.json`, `basic_servant.json`, `basic_equip.json`, `basic_event.json`, `nice_gacha.json`) straight from the browser: `info.json` at most every six hours while the page is open, the lists only when NA's data changed. A short summary is kept in `localStorage` under `spirit-origin-list:v1:live`. The code is in `src/app/24-live-na.js`. The test copies start with it switched off; `tests/test_17_live_na.py` turns it on against a local stand-in.

## Event pages and NA banners (0.22.0, tabs since 0.22.2)

Pressing an event in "On NA now" opens `#event/<id>` (or `#event/<id>/<tab>`), in `src/app/25-event-page.js`. The page shows one tab at a time:

- **Tabs from the wiki.** The Fate/Grand Order fandom wiki's NA event pages start with an `{{EventHeaderNA}}` (the event's exact name, start date, requirement) and a `<tabber>` of transcluded pages (`Main Info={{:Page/Main Info}} |-| Event Shop=…`). The page whose header names the event (or starts closest to it) is used; each tab's page is fetched through the MediaWiki API (`origin=*`) when it's opened, then the rest in the background. A page without a tabber is split at its headings.
- **Atlas Academy for the exact parts.** `/nice/NA/event/<id>`, its wars, the free quests' drops, `nice_item.json` and `basic_svt.json` give the shop (per currency, with totals), the calculator, the mission list and random missions by rank, free-quest drops, banners (with Simulate) and point rewards. Without the wiki, the tabs come from this data alone.
- **The filter.** Wiki HTML is rebuilt in an inert document keeping only plain tags, `href`/`src` that point to the web or the wiki's image servers, and `colspan`/`rowspan`. The wiki's phone-only copies (`.mobile-only`), hidden parts and tooltip buttons are left out; a tooltip's text becomes the `title`. The wiki's tabbers become this page's own tabs. Servant and Craft Essence icons carry their numbers (`S327A1Icon`, `CEIcon1498`), so links to servants, their Noble Phantasms and Craft Essences open Past Chaldea instead of the wiki.
- **Cache.** Events, wiki tabs and pages, item and servant names are kept in IndexedDB `fate-grand-index-cache` (separate from the pictures database); the 30 most recently opened events are kept.

The calculator uses each servant's ascension and skill materials (`ma`/`ms` in `atlas_data.js`, items in `ATLAS_MATS`). "Simulate" loads an NA banner into the summoning simulator (`src/app/26-banner-sim.js`). `tests/test_18_event_page.py` covers all of it against stand-ins; the wiki stand-in copies the markup of a real NA event page.

## Your data

Your roster is stored in your browser: `localStorage` key `spirit-origin-list:v1`, pictures in IndexedDB `spirit-origin-list-images`. These names never change, so existing saves keep working with every new version.

Importing a backup or a spreadsheet replaces entries that share an ID, so the page keeps a copy of the list in memory first and offers **Undo import** until you press Keep it, import again or reload (`importSnap` / `importUndo` in `src/app/07-core-rendering-forms-events.js`). If a save fails because the browser's storage is full, `#save-warn` stays above the page until a save works again. In Chrome, every page opened from a file shares one storage space (`file://`), so other local pages count toward the same limit.
